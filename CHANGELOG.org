#+TITLE: Spacewave Changelog

* v0.56.1
<2026-07-18 Sat>

Spacewave 0.56.1 adds new Canvas tools, Storage Health and recovery guidance,
contextual browser tab titles, and version-specific release pages. It also
improves Drive uploads, invites, device linking, multi-tab browser use, Terminal
continuity, experimental V86 VM setup, and Windows desktop startup.

** Features
- Canvas now includes line, arrow, rectangle, and ellipse tools, plus an image
  picker for placing pictures from Drive.
- Session settings now include Storage Health, showing browser usage, cleanup
  protection, sync activity, and recovery options for freeing space, linking
  another device, using Spacewave Cloud, or exporting important Spaces.
- Dragging several selected Drive items into a layout now opens one Spacewave
  tab per item, in selection order.
- The Command Palette now includes Select Account for switching directly between
  available accounts.
- Each changelog release now has its own page with desktop downloads pinned to
  that version.

** Fixes
- Large Drive selections now upload up to three items at a time and publish each
  completed file immediately; one failed file no longer stops the rest of the
  selection.
- When browser file storage is full, Drive now shows capacity and recovery
  guidance and removes incomplete data instead of consuming more space on
  repeated failures.
- Invite links opened without an active session now survive sign-in and session
  setup, then open the shared Space after acceptance.
- Fixed multiple browser tabs and popouts so their Spacewave tab list stays in
  sync while each page keeps its own active tab, URL, and layout.
- Terminal command sessions now survive pane remounts when a split layout
  collapses, instead of ending with a session failure.
- Fixed Windows desktop startup so packaged releases open Spacewave normally
  without stray console windows.
- When a Space has no configured home object, Spacewave now shows its object
  list instead of an empty view.

** Improvements
- Browser tab titles now follow the active section, Space, object, selected
  viewer, or focused layout pane, making tabs and bookmarks easier to identify.
- Device linking now lets you click the code to copy it, shows ordered
  connection progress, and surfaces direct-link failures instead of leaving an
  indefinite spinner.
- Experimental V86 VM setup now stays in its wizard and reports real image-copy
  and creation progress, with Retry for recoverable failures.
- Terminal now shows a Connecting state while it opens, and Command Line output
  renders more consistently across pane changes.
- Browser file storage now requests protection from automatic cleanup after the
  first successful save, reducing eviction risk without delaying startup.
- Browser startup now waits until app features are fully ready before leaving
  the loading flow, reducing blank or partially initialized views after updates.

** Security
- Password and backup recovery keys are now separate actions, so generating a
  backup key no longer also adds the password entered for the session.

Terminal in browser builds, and reduces byte-copying during browser startup and

  deleting the selected object with explicit confirmation.

** Improvements
- Cold browser starts are faster: startup checksum processing is 55.7× faster,
  eliminating the largest measured cold-boot bottleneck.
- Local file storage now avoids duplicate integrity work while preserving
  compatibility with existing stored data, reducing repeated work during startup
  and file access.
- The shortcut editor now shows held modifiers while recording, formats captured

  replace action.

* v0.51.0 Public Launch
<2026-05-01 Fri>

Spacewave is open-source, private, self-hosted, multiplayer Spaces (apps) that
store data wherever you want, work offline through peer-to-peer networking, and
sync instantly with real-time streaming multiplayer. v0.51 is the public launch:
a suite of first-party Spaces, a plugin SDK to build your own, and desktop, web,
and CLI clients, all Apache-2.0 licensed. Try it at
[[https://spacewave.app][spacewave.app]] in one click with no account required,
read the [[https://spacewave.app/blog/2026/04/launch][launch announcement]],
grab the code at
[[https://github.com/s4wave/spacewave][github.com/s4wave/spacewave]], or
[[https://discord.gg/KJutMESRsT][join the community on Discord]] and let us know
what you want added next.

** Features

- Spaces: shared multiplayer workspaces. Add your friends or coworkers and
  collaborate live, with role-based access and invite flows.
- Drive: store and access your files. Drag-and-drop upload, projected downloads,
  zip export, and live file watching across linked devices.
- Notes: write and collaborate with Markdown text files. Offline-first, with
  inline previews and live editing.
- Chat: communicate securely with humans or robots. End-to-end encrypted and
  synced across linked devices, online or offline.
- Canvas: an infinite 2D workspace for visual thinking, with embedded live
  objects from any other Space.
- Git: browse repositories with branches, tags, commit history, and tree views.
  No clone or terminal needed.
- Media: photo gallery and inline image previews wherever files appear in the
  app.
- Plugin SDK: write your own Spaces in TypeScript or Go with hot reload, or
  install plugins from any Git repo. Same APIs the first-party plugins use.
- Cross-platform: desktop apps for macOS, Windows, and Linux, a one-click web
  app, and a CLI, all built from a single Go and TypeScript codebase.
- Account and session management: passkeys, account recovery, multi-device
  session linking, and session self-rejoin.
- Spacewave Cloud (optional): encrypted 100GB backup for $8/mo. Private, secure,
  fast (via Cloudflare), and dead simple. The app works fine without it.

** Security

- End-to-end encrypted storage and messaging across all linked devices. Keys
  live on your devices and never leave them unless you explicitly export a
  backup.
- Spacewave Cloud backups are encrypted on your device before they are uploaded.
  The cloud only ever sees encrypted data.
