#+TITLE: Spacewave Changelog

* v0.51.4
<2026-05-09 Sat>

Spacewave 0.51.4 is a reliability release for browser and desktop startup.
Updates recover more reliably during rollout, browser tabs resume with fewer
stale views, and cold browser loads do less work before the first useful screen
appears.

** Fixes
- Fixed update checks so the desktop app keeps retrying when release information
  is not ready at launch, instead of leaving update status stuck on an old
  error.
- Fixed release loading so Spacewave can recover when local update files are
  incomplete, reducing blank or stuck loading screens during a rollout.
- Fixed restored or foregrounded browser tabs so reconnect timing waits until
  the page is ready, reducing stale views and unnecessary app reloads.
- Fixed updater status for releases that do not include a desktop app update for
  the current platform, so old update errors are cleared.

** Improvements
- Browser startup now loads less of the app before showing the first relevant
  screen, improving cold-load performance for sign-in, Quickstart, docs, and
  active sessions.
- Browser resume handling now distinguishes a slow foregrounded tab from a
  broken connection, making return-to-tab recovery less disruptive.
- Release file recovery now reuses verified local files after a successful
  fetch, reducing repeat work on later starts.

* v0.51.3
<2026-05-08 Fri>

Spacewave 0.51.3 improves desktop and browser startup/update reliability, adds a
tray/menu-bar update action, and fixes rough edges in Cloud setup, Drive video
previews, and session recovery status.

** Features
- The desktop tray/menu bar now shows an Install Update action when a Spacewave
  desktop update is ready.

** Fixes
- Fixed a desktop startup problem where Spacewave could keep running without
  showing a window after an update.
- Fixed Spacewave Cloud setup and billing actions in split views so checkout,
  cancellation, and reactivation stay in the active panel instead of jumping to
  the wrong session page.
- Fixed browser updates and root-page reloads so fresh tabs are less likely to
  show an old or blank Spacewave page.
- Fixed Drive video previews so restored video tabs and back/forward navigation
  return to playable previews.
- Fixed the desktop tray Settings action so it opens Command Line settings for
  the active session.

** Improvements
- Browser startup can show the app frame earlier, reducing time spent on the
  initial loading screen during cold web loads.
- Session recovery status now looks the same in the app and the desktop tray,
  including pending Spaces, unlock prompts, retries, and failures.
- Command Line guidance now reflects the tray/menu-bar runtime, making it
  clearer when CLI commands can connect after all Spacewave windows are closed.

* v0.51.2
<2026-05-07 Thu>

Spacewave 0.51.2 makes Drive workspaces, sharing, and desktop use easier while
improving sign-in, session recovery, browser updates, and local file storage
reliability.

** Features
- Drive workspaces now open directly into a file browser for folders, uploads,
  downloads, and organization.
- You can copy a public link to the current view from the app, making it easier
  to share the exact Spacewave page you are using.
- Space sharing can now invite someone by Spacewave username, with pending
  invites shown in the app for accept or decline.
- The desktop app now has a native desktop tray or menu bar item for reopening
  Spacewave, checking sessions and Spaces, and quitting cleanly.
- The desktop app can add and open existing local Spacewave data directories
  from the sign-in and session screens.

** Fixes
- Fixed invite links copied from the desktop app so recipients open the shared
  Space in Spacewave correctly.
- Fixed newly created Spaces disappearing from the Space list after refresh.
- Fixed browser startup paths that could leave the app stuck on the loading
  screen after opening account emails.
- Fixed desktop launch and quit behavior so the app no longer reopens
  unexpectedly or stalls before showing a window after an update.
- Fixed desktop file pickers so hidden local Spacewave folders can be selected
  when needed.
- Fixed the Space details object list so it updates while the details panel
  stays open.
- Fixed Space deletion so the confirmation dialog stays populated and the
  visible delete step completes faster.
- Download and other off-site links now open in a separate tab instead of
  replacing the running Spacewave page.

** Improvements
- Sign-in now shows clearer in-progress feedback while passkey, browser, or SSO
  authentication is running.
- Session recovery after sign-in now runs in the background, with a compact
  status indicator and unlock prompts only when a Space needs your account key.
- Browser updates are more reliable when tabs reload, regain focus, or come back
  online, reducing stale or mixed app versions after a release.
- Browser file storage is more durable after interrupted writes or restored
  tabs, reducing stale file views and startup failures.
- Drive and file browser controls are clearer, with improved toolbar actions,
  selected-row states, retryable file loading errors, and better
  unavailable-preview messages.
- The desktop tray shows session, Space, update, and attention status even when
  all windows are closed.

** Security
- Username-addressed invites are tied to the intended Spacewave account and
  require recipient acceptance before access is granted.

* v0.51.0 Public Launch
<2026-05-01 Fri>

Spacewave is open-source, private, self-hosted, multiplayer Spaces (apps) that
store data wherever you want, work offline through peer-to-peer networking, and
sync instantly with real-time streaming multiplayer. v0.51 is the public launch:
a suite of first-party Spaces, a plugin SDK to build your own, and desktop, web,
and CLI clients, all Apache-2.0 licensed. Try it at
[[https://spacewave.app][spacewave.app]] in one click with no account required,
read the [[https://spacewave.app/blog/2026/04/launch][launch announcement]],
grab the code at
[[https://github.com/s4wave/spacewave][github.com/s4wave/spacewave]], or
[[https://discord.gg/KJutMESRsT][join the community on Discord]] and let us know
what you want added next.

** Features

- Spaces: shared multiplayer workspaces. Add your friends or coworkers and
  collaborate live, with role-based access and invite flows.
- Drive: store and access your files. Drag-and-drop upload, projected downloads,
  zip export, and live file watching across linked devices.
- Notes: write and collaborate with Markdown text files. Offline-first, with
  inline previews and live editing.
- Chat: communicate securely with humans or robots. End-to-end encrypted and
  synced across linked devices, online or offline.
- Canvas: an infinite 2D workspace for visual thinking, with embedded live
  objects from any other Space.
- Git: browse repositories with branches, tags, commit history, and tree views.
  No clone or terminal needed.
- Media: photo gallery and inline image previews wherever files appear in the
  app.
- Plugin SDK: write your own Spaces in TypeScript or Go with hot reload, or
  install plugins from any Git repo. Same APIs the first-party plugins use.
- Cross-platform: desktop apps for macOS, Windows, and Linux, a one-click web
  app, and a CLI, all built from a single Go and TypeScript codebase.
- Account and session management: passkeys, account recovery, multi-device
  session linking, and session self-rejoin.
- Spacewave Cloud (optional): encrypted 100GB backup for $8/mo. Private, secure,
  fast (via Cloudflare), and dead simple. The app works fine without it.

** Security

- End-to-end encrypted storage and messaging across all linked devices. Keys
  live on your devices and never leave them unless you explicitly export a
  backup.
- Spacewave Cloud backups are encrypted on your device before they are uploaded.
  The cloud only ever sees encrypted data.
