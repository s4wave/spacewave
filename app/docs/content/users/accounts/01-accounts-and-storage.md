Spacewave has two separate decisions that are easy to mix together:

- How you authenticate.
- Where the session and Space data are stored.

A local session lets you keep working without a cloud account. It is fast to start and useful for trials. Its risk is durability: if local browser or device state is lost, Spacewave cannot recover data that was never backed up.

A Spacewave Cloud account gives you Provider Account identity and cloud-facing session features. Depending on the plan and setup, it can also give you stronger storage and device migration paths.

## When to Stay Local

Stay local for trials, disposable experiments, and small Spaces you can recreate.

Before using a local session for important work, complete [Backup and Lock Setup](/docs/users/accounts/backup-and-lock-setup).

## When to Use Cloud

Use cloud-backed setup when you need account recovery, device moves, or storage that survives browser data loss.

Cloud does not remove local-first behavior. The Space still opens through the Spacewave app. The difference is the provider and recovery path behind the session.

## Storage Prompt

Spacewave may show setup guidance after a local session grows. Treat that as a signal to choose a safer persistence path before importing more files.
