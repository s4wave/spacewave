Linking gives a second device access to your Spaces. You confirm the link on
both devices by comparing a row of emoji, so nobody can slip in between.

## Link with a code

This works whether or not you have a Spacewave Cloud account:

1. On either device, open the link-device flow from setup or settings.
2. On the first device choose **Generate code for another device**. On the
   second choose **Enter a code from another device**.
3. Type in the 8-character code.
4. Both devices show a row of emoji. Check that they match.
5. Confirm on both.

The emoji step is the part that matters. If the two rows differ, stop and start
over.

## Link without going through the cloud

If your Spaces live only on this device, you can link two devices sitting next
to each other without any server in the middle. One device shows a block of text
or a code to scan, the other reads it and hands back a reply. You still compare
emoji before it finishes.

This option is only offered for Spaces kept on the device. With a Spacewave
Cloud account, use the code above.

## After they are linked

The second device can open the same Spaces as the first. You can unlink it later
from settings, which takes that access away again.

Linking a device is not the same as adding a device for Spacewave to manage.
That is a separate feature, for machines you want to keep track of, with their
own status and setup.
