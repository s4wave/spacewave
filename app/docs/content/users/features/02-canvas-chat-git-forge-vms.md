A Space is a container for one project in Spacewave. Besides files and writing,
it can hold the items below. To add one to a Space, use the create command in
the command palette or the add button in the Space.

## Canvas

A canvas is a board where you lay out an idea visually instead of as a list.
You can drag items around and group them. The **Create a Canvas** Quickstart
makes a Space with a small demo on the board, so it does not start blank.

## Git

A Git repository can live in a Space like any other item. The
**Create/clone a Git Repository** Quickstart walks you through creating a new
repository or cloning an existing one. You can then browse the repository and
its branches in Spacewave.

## Chat

A chat channel keeps a conversation next to the work it is about, instead of
in a separate app. You can add a chat channel to any Space. The **Start a
Chat** Quickstart, which creates a new Space with a channel in it, is
experimental and may not appear.

## Forge

Forge runs jobs for you. You set up workers that do the work, clusters that
group them, and jobs made of tasks, and a dashboard shows their progress. You
can add these Forge items to any Space. The **Create Forge Dashboard**
Quickstart sets up a working example at once. That Quickstart is experimental
and may not appear.

## Virtual machines

A V86 VM is an x86 computer that runs in a browser tab, inside a Space. Adding
one copies a starter disk image for you. VMs are experimental and may not
appear. They also depend on an add-on. Without it, the VM appears in the Space
but does not open.

## If something is missing

A missing Quickstart or item means that feature is not available in this copy
of Spacewave. It is not a problem with your Space, and nothing you already made
is affected.
