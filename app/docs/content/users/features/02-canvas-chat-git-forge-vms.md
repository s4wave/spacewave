Spacewave can host many object surfaces, but they are not all equally ready for every user.

## Release-Visible Surfaces

Canvas and Git are visible user Quickstarts in the current app.

Use Canvas for visual organization. It can hold nodes and links, and it can point at objects in the Space.

Use Git when you want a repository object in a Space. The Git Quickstart opens a persistent create or clone wizard before handing off to the repository.

## Experimental Surfaces

Chat, Forge, and V86 are development or experimental Quickstarts unless your build exposes them.

Chat is a Space-native messaging surface.

Forge is a task orchestration surface with clusters, jobs, tasks, workers, passes, and executions.

V86 is a browser VM surface that depends on VM image objects and runtime plugin behavior.

## How to Choose

Pick the surface with the clearest first action. If you are storing files, choose Drive. If you are organizing work visually, choose Canvas. If you are testing platform objects, use the experimental surfaces in a development build.
