A **Space** is the durable workspace. A Space contains objects. Each object has an **ObjectType**, such as file storage, Git repository, Canvas, or a development-only docs object.

The first screen for a Space is a **Space App Surface**. It is selected by `SpaceSettings.index_path`. A Drive Space opens in Drive. A Canvas Space opens in Canvas. A Git Quickstart may first open a persistent wizard, then hand off to the Git object when the wizard finishes.

## Primary Surface

The primary surface is optimized for the job the Space was created to do. Treat it as the front door.

Use it when you want to work normally:

- Drive for files.
- Canvas for visual organization.
- Git for repository work.
- A wizard route while a persistent object still needs setup.

## Object Browser

The object browser is the escape hatch. Use it to inspect object keys, open a different object, or recover from a Space whose primary route no longer points where you expected.

The object browser does not replace the primary surface. It shows the substrate. The primary surface explains what the Space is for.

## Collaboration and Ownership

Ownership belongs to the Space and its backing account or organization state. Moving a Space between owners is different from copying a file out of Drive. If you operate shared or hosted Spaces, read [Teams and Space Ownership](/docs/self-hosters/ownership/teams-and-space-ownership).
