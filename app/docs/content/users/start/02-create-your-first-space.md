Choose a Quickstart by the job you want the Space to do.

- **Create a Drive** gives you a file workspace with folders, uploads, downloads, and a first-run Drive screen.
- **Create an Empty Space** gives you a blank container where you can add objects later.
- **Create or clone a Git Repository** opens a persistent Git wizard before it creates the repository object.
- **Create a Canvas** creates a visual workspace for arranging objects and notes.

After creation, Spacewave opens the Space at the route stored in its `SpaceSettings.index_path`. That route is the Space's primary surface. The object browser remains available when you need to inspect the objects behind the main view.

## First Useful Check

For a Drive, create a folder and add a small text file. Reload the app, return to the Space, and confirm the file still opens.

For an empty Space, open the object browser and create one object that matches your workflow. Keep the first Space boring; it is better to prove persistence before adding several surfaces.

## Local Session Warning

A local session lives on this device. Browser storage is convenient but less durable than a managed storage setup. If the setup banner appears after the session grows, follow it before continuing with important data.

Read [Accounts and Storage](/docs/users/accounts/accounts-and-storage) before choosing where long-lived work should live.
