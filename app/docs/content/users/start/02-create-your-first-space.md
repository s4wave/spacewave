A Space is a container for one project in Spacewave. A Quickstart creates a
Space and puts a first item in it, so you start with something to open instead
of an empty screen.

## Create the Space

1. Open Spacewave.
2. Choose a Quickstart: **Create a Drive**, **Create an Empty Space**,
   **Create/clone a Git Repository**, or **Create a Canvas**.
3. If you have not signed in, let Spacewave set up an account on this device.
4. Wait for the setup to finish.

Spacewave opens the new Space as soon as it is ready.

## What each Quickstart gives you

- **Create a Drive** sets up file storage and writes a `getting-started.md` for
  you to open. It opens the file browser with a short guide at the top.
- **Create a Canvas** sets up a board for arranging items visually, with some
  starter content.
- **Create/clone a Git Repository** opens a short setup flow. You can create a
  new repository or clone an existing one.
- **Create an Empty Space** gives you a Space with nothing in it, ready for
  whatever you add next.

Some Quickstarts, such as notebooks and chat, are still experimental. Your copy
of Spacewave may not show them. A missing Quickstart means that feature is not
available in this copy. It does not mean something is wrong with your Space.

## Check that it worked

Open the first item and check that it looks right. For a Drive, open
`getting-started.md` and read the starter guide. For an empty Space, open the
command palette with Cmd+K or Ctrl+K and use the create command to add an item.

Then add something and reload the page. If it is still there, your Space is
saving your work.

## Before you rely on it

A Space you create without an account stays on the device that made it.
Signing in to Spacewave Cloud adds sync, backup, and access from your other
devices. See [Move to Cloud](/docs/users/accounts/move-to-cloud).

If this Space will hold work you cannot recreate, download a backup key and
choose a lock mode now. [Backup and Lock
Setup](/docs/users/accounts/backup-and-lock-setup) explains both.
